 ## PRV-1531

This project is based on materials by Xavier Serra and Błażej Kotowski for the course **Audio Systems and Coding** at Universitat Pompeu Fabra.

The functions are based on those used in the lab notebooks. I modified them while I was a student in the course to better suit the project’s needs.


## Requirements
To work with this notebook, install:
- **VS Code**
- **Python 3.12**
- **Git** or **GitHub Desktop**

In VS Code, install the **Python** and **Jupyter** extensions.


## Set up a virtual environment

The virtual environment keeps this project’s Python packages separate from other projects.

### Windows

Run these commands in the project folder using PowerShell or the CMD:

```powershell
py -3.12 -m venv .venv
.\\.venv\Scripts\Activate.ps1
```

### Windows

Run these commands in the project folder:

```powershell
python3.12 -m venv .venv
source .venv/bin/activate
```
